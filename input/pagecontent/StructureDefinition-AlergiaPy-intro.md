El Perfil **Alergia-PY** se deriva del recurso FHIR AllergyIntolerance.
 Define los requisitos mínimos para representar alergias y reacciones adversas asociadas a un paciente dentro de los sistemas de información de salud de Paraguay.
 
Este perfil especifica los elementos básicos obligatorios, las extensiones nacionales, los vocabularios y conjuntos de valores que DEBEN estar presentes, y restringe el uso de los elementos para garantizar consistencia, seguridad e interoperabilidad en la gestión de alergias en entornos clínicos.
